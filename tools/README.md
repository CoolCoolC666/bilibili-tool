# 独立工具

v3.1.0+ 配套的独立分析工具，跟主程序解耦。

## `analyze_xlsx.py`（v3.1.0+ 配套）

把 `output/xlsx/author_detail_*.xlsx` 多个文件合并分析，输出基础统计、年度分布、爆款 TOP 10、互动率、有趣发现等。

**v3.1.1 隐私设计**：UP 主姓名全部匿名化为 `UP-A/B/C/D`（按 UID 升序），真实姓名仅在脚本内部维护，输出文件不暴露。

### 用法

```bash
# 默认：读项目内 output/xlsx/ 目录
py -3.13 tests/analyze_xlsx.py

# 自定义数据目录
py -3.13 tests/analyze_xlsx.py --data-dir "E:/我的数据/整合"

# 输出到指定文件
py -3.13 tests/analyze_xlsx.py --out _analyze_out.txt
```

### 工作流

1. 用 Web 端跑按 UP 主抓取，生成 `output/xlsx/author_detail_*.xlsx`
2. 跑 `analyze_xlsx.py` 整合分析（自动找 `output/xlsx/` 目录）
3. 看 `_analyze_out.txt` 里的洞察，找创作规律 / 爆款 / 互动率

### 数据洞察应用

| 场景 | 用法 |
|---|---|
| 找 UP 主创作趋势 | 看「年度分布」矩阵 |
| 找爆款规律 | 看「爆款视频 TOP 10」+ 互动率 |
| 评估粉丝粘性 | 看「互动率（赞/播放）」 |
| 验证 disableCache 效果 | 看「v3.1.0 修复效果」对比（99.6% vs 79.3%）|

### 不依赖主程序

- 只需要 `openpyxl`（已在 `requirements.txt`）
- 不需要 Flask / Web 端
- 不需要 API key
- 单文件可移植（可以拷到任何 Python 环境跑）

### 隐私保证

- ✅ 输出文件不包含真实 UP 名
- ✅ 标题里的 UP 名已脱敏（如 `【warma】xxx` → `【UP-A】xxx`）
- ✅ BVID 是公开信息（任何人都能查 B 站），保留
- ✅ 真实姓名映射仅在 `tests/analyze_xlsx.py` 顶部 `_REAL_NAMES` 字典
- ❌ 如果把脚本源码公开，**不要**同时公开 `_REAL_NAMES` 字典
